## Featured Projects

### 1. PropertyLens — Residential Real Estate Analytics

**Project type:** Exploratory Data Analysis  
**Domain:** Residential Real Estate  
**Primary language:** Python

PropertyLens explores residential property listing data from Gurugram to understand differences in listed prices across localities and property characteristics.

The project focuses on cleaning the dataset, examining its distributions, comparing property segments, and using statistical analysis to explore factors associated with listed prices.

#### Objectives

- Prepare the property listing data for analysis.
- Examine the distribution of residential property prices.
- Compare median prices across localities and other property categories.
- Explore relationships between property area and listed price.
- Use visualisations to communicate patterns in the dataset.

#### Work Performed

- Cleaned the dataset and removed duplicate records.
- Explored property prices and differences across localities.
- Analysed median prices across selected property categories.
- Examined price-versus-area patterns.
- Created visualisations to present the findings.
- Applied statistical methods to investigate relationships in the data.

#### Dataset Summary

| Metric | Value |
|---|---:|
| Original records | 19,515 |
| Duplicate records removed | 5,290 |
| Visualisations created | 8 |

These figures describe the dataset and work documented in the project.

#### Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- SciPy
- Statsmodels
- Jupyter Notebook

#### Skills Practised

Data cleaning, duplicate handling, exploratory data analysis, descriptive statistics, data visualisation, and statistical analysis.

**Repository:** [PropertyLens — Residential Real Estate Analytics](https://github.com/sh29sarathe/PropertyLens-Residential-Real-Estate-Analytics)

### 2. E-Commerce Sales & Customer Analytics

**Project type:** SQL Analysis and Business Intelligence  
**Domain:** E-Commerce  
**Primary tools:** MySQL and Power BI

This project examines sales performance, order cancellations, customer behaviour, and product performance using a synthetic e-commerce dataset.

The workflow combines relational database analysis with Power BI reporting. SQL queries are used to investigate the data, while a two-page dashboard presents key metrics and analysis in a visual format.

#### Objectives

- Organise the dataset into relational database tables.
- Analyse sales and order-related information using SQL.
- Examine customer behaviour and product performance.
- Investigate order cancellations and relevant sales patterns.
- Present key metrics through a Power BI dashboard.

#### Work Performed

- Worked with a relational database containing five tables.
- Analysed 1,500 orders using SQL.
- Used joins, common table expressions, aggregations, and window functions.
- Created analytical views for reporting and further analysis.
- Connected the analysis to Power BI.
- Developed a two-page dashboard for exploring the results.

#### Project Summary

| Metric | Value |
|---|---:|
| Relational tables | 5 |
| Orders analysed | 1,500 |
| Dashboard pages | 2 |

#### Technologies Used

- MySQL
- SQL
- Common Table Expressions (CTEs)
- JOINs
- Window Functions
- Analytical Views
- Power BI
- DAX

#### Skills Practised

Relational data analysis, SQL querying, database joins, aggregations, analytical reporting, KPI presentation, dashboard development, and data visualisation.

**Important:** The project uses a synthetic dataset. The reported figures describe the project dataset and should not be interpreted as results from a real business.

**Repository:** [E-Commerce Sales & Customer Analytics](https://github.com/sh29sarathe/e-commerce-sales-customer-analytics)

## Run the Website Locally

You can run the portfolio directly on your computer without installing a framework or additional packages.

### Prerequisites

- A modern web browser
- The portfolio source files
- The complete `assets` folder

### Steps

1. Download or clone the repository.
2. Ensure that `index.html`, `style.css`, `script.js`, and the `assets` folder are in the correct locations.
3. Open `index.html` in your web browser.
4. Navigate through the website and test the project links, CV links, navigation, and contact button.

For a more reliable local preview, you can also open the folder in Visual Studio Code and use a local development server extension.

### Publishing the Website

The portfolio can be published as a static website using GitHub Pages.

Once the repository is uploaded and configured for deployment, GitHub Pages will provide a public URL that can be shared with recruiters and included in my CV and LinkedIn profile.
